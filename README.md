# AtendeIA

Sistema de atendimento automatizado desenvolvido
com Python, FastAPI e integração com IA.

## Objetivo
Simular o atendimento de clientes de uma loja
virtual, permitindo consultar pedidos, responder
dúvidas e registrar conversas.

## Tecnologias
- Python
- FastAPI
- SQLite
- HTML, CSS e JavaScript

## Status
Em desenvolvimento.

## Como executar
1. Criar e ativar um ambiente virtual Python.
2. Instalar dependências com:
   pip install -r requirements.txt
3. Executar:
   fastapi dev main.py
4. Acessar:
   http://127.0.0.1:8000/docs
